This practical contains a program about accessing file contents and use of header files to solve the Magic-Square problem.

The c code is saved in 'main_stub.c' and the header file is in 'magic_square_stub.h'

2. The header file contains the function and its definition.

To compile the code use gcc main_stub.c -o output -lm
