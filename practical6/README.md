This is a practical on Matrix multiplication and how to make and use 'Makefile'. They are three files: 'matrices.c', 'matmult.c', and 'Makefile'.

The 'matrices.c' file contains the main code that multiplies two matrices. It calls a function which is defined and stored in the file 'matmult.c' which multiplies the matrices. Therefore the 'Makefile' gives a way of linking the two files during compilation to produce an output.

To run use 'make'
