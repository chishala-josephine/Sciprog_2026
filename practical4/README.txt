The file Functions.c contains a c code that uses the trapezoidal rule to approximate the value of an integral which is the area under a curve, while applying functions and arrays.

The function 'degtorad' converts degrees to radians then the function 'traprule' uses the trapezoidal rule to return the area for an array of values decalred in the global array 'TanArr[N+1]'.

The file can be compiled using `gcc` followed by the filename.

To execute the code use ./output filename
