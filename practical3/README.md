This is Practical 3

This practical contains three C files: `printing.c`, `trap1.c`, and `trap2.c`.

1. printing.c
   This file contains a C code that shows how to print output using the `printf()` function. The practical focuses on using different placeholders (format specifiers) in `printf()`.

2. trap1.c and trap2.c
   These files contain C codes that use the trapezoidal rule to approximate the value of an integral. The two codes shows two different ways of doing this the to calculate the area under a curve.


Each file can be compiled using `gcc` followed by the filename. For example:
gcc printing.c

To execute the code use ./output filename
